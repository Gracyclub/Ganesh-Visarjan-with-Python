# 🌺 Lord Ganesha Visarjan Animation in Python

An emotional and minimal sketch-style animation of **Lord Ganesha's Visarjan (Immersion)** created entirely using **Python** and **Pygame**. 

The project features a continuous water wave simulation, hand-drawn wobbly ripple physics, and background transparency processing for the sketch.

---

## ✨ Features
- **Real-time Pygame Rendering:** Smooth 60 FPS graphical popup animation.
- **Dynamic Water Ripples:** Mathematical sine-wave water surface with organic oval ripple distortion.
- **Automatic Background Removal:** Removes light/white backgrounds from idol sketches on the fly using `PIL`.
- **Text & Visual Overlay:** Minimal typography featuring *"Ganpati Bappa Morya! Agle baras tu jaldi aa..."*.

---

## 🛠️ Requirements
Make sure you have Python installed. Install the required libraries via terminal:

```bash
pip install pygame pillow
```

---

## 🚀 How to Run

1. Clone or download this repository:
   ```bash
   git clone [https://github.com/Gracyclub/ganesh-visarjan-with-python.git](https://github.com/Gracyclub/ganesh-visarjan-with-python.git)
   cd ganesh-visarjan-with-python
   ```

2. Place your Ganesha sketch image named **`bappaa.jpg`** in the project directory.

3. Run the Python script:
   ```bash
   python main.py
   ```

> **Controls:** Press **`R`** anytime to restart the Visarjan animation.

---

## 💻 Tech Stack
- **Language:** Python
- **GUI & Physics:** Pygame
- **Image Processing:** Pillow (PIL)
